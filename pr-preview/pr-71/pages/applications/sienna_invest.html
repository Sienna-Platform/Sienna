Sienna\Invest

Plan generation and transmission for the future

Exceptional performance for large data

Features and Capabilities

Key Features

  • Well-defined data structures for potential generation and transmission investments
  • Model least-cost investment decisions at the nodal level

Core Capabilities

  • Generation and transmission investment planning
  • Built-in interoperability with Sienna\\Ops and Sienna\\Network to assess operational and reliability impacts of investments

PowerSystemsInvestmentsPortfolios.jl

Define options for new investments

PowerSystemsInvestments.jl

Model generation and transmission expansion

PowerSystems.jl

Consistently represent data for existing devices

How It Works

Sienna\Invest is a modular platform using software packages written in the Julia programming language. All packages are open-source, free to use, and have a command-line interface. See the Documentation page for each package's documentation, general installation instructions, and tutorials.
